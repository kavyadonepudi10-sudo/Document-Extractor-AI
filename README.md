\# LLM Document Information Extractor



A practical, interactive Python utility that parses unstructured business documents (invoices, receipts, contracts) and uses Google Gemini to extract key fields into a clean, standardized JSON schema.



\## What It Does

Instead of relying on rigid, breakable regex patterns or limited classical NLP packages, this tool leverages Gemini's contextual understanding to intelligently map messy text to structured data. It also includes automatic model fallback routing to handle traffic spikes smoothly.
